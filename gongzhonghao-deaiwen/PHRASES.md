# AI 味词表与替换规则

诊断和替换时的对照手册。按类别查表，左栏命中即标注，右栏为默认改写方向。

## 1. 开头套话（整句删除）

| 黑名单 | 处理 |
|--------|------|
| 在当今……的时代 / 在这个……的社会 | 删，直接从事件进入 |
| 随着……的发展/普及/深入 | 删，或改为具体时间点 |
| 近年来 / 如今 / 当下 | 删；确需时间状语时给具体年份 |
| 不知从何时起 / 众所周知 | 删 |
| 你有没有发现 / 相信大家都…… | 删，改为直接陈述 |

## 2. 空洞总结句（删除或具体化）

| 黑名单 | 替换方向 |
|--------|----------|
| 这无疑具有（重要）意义/价值 | 删；或写明具体对谁产生什么影响 |
| 毋庸置疑 / 不言而喻 / 显而易见 | 删 |
| 取得了显著成效/成果 | 换成具体数字 |
| 发挥了重要作用 | 写明确切作用是什么 |
| 助力/赋能/加持 XX 发展 | "帮 XX 做到了 Y" 或删 |
| 为……提供了新思路/新路径/借鉴 | 删 |
| 综上所述 / 总而言之 / 值得注意的是 | 删 |

## 3. 高频 AI 句式（结构性改写）

| 句式 | 问题 | 改法 |
|------|------|------|
| 不是……而是…… | AI 使用频率约为人类的 20 倍 | 直接说"而是"后面的内容 |
| 不仅……而且/更…… | 递进堆砌 | 拆成两个独立短句 |
| 一方面……另一方面…… | 假装客观 | 保留作者真实倾向的那一面 |
| 从某个角度来看 / 在某种程度上 | 回避立场 | 敢下判断就直说，不确定就写明"我猜" |
| 越是……越是…… / 越……越…… | 对偶腔 | 打破对称，说人话 |
| ……的背后，是…… / ……折射出…… | 故作深刻 | 直接陈述因果 |
| 看似……实则…… | 同上 | 同上 |
| 这不仅仅是……更是…… | 升华癖 | 删前半句或后半句 |
| 与其说……不如说…… | 同上 | 只留后面的判断 |

## 4. 结尾腔（全部禁止）

| 黑名单 | 改法 |
|--------|------|
| 未来已来 / 让我们拭目以待 | 停在具体信息上 |
| 你准备好了吗？/ 你怎么看？（评论区见） | 删；互动引导单独成段不用问句升华 |
| 愿每个……都能…… | 删 |
| 相信在不久的将来…… | 删 |
| 总之，只有……才能……（条件+愿景式总结） | 删 |

## 5. 副词与形容词（默认删除）

非常、极其、十分、格外、颇为、无疑、明显、显著、巨大、深深、狠狠、满满

例外：口语化文本中"特别、真的、太"各保留至多 3 处，它们是自然的。

## 6. 排比与节奏

- 三项并列（"更高效、更便捷、更智能"）：保留一项，删两项
- 全文破折号"——"出现 ≥ 2 次：视为 AI 痕迹，改用逗号或拆句
- 每段首句都是观点句：至少打乱两段，用故事或数据开头

## 7. 保留判断

以下不算 AI 味，不要误伤：
- 行业术语在专业文中正常使用
- 刻意的口语梗、方言、作者个人化的重复修辞
- 短促有力的排比（全文最多允许 1 处，作为修辞而非惯性）
